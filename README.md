📚 Gerenciador de Biblioteca com PostgreSQL, Tkinter e Faker
Este projeto é uma aplicação simples de gerenciamento de biblioteca, desenvolvida em Python, que utiliza um banco de dados PostgreSQL para armazenar informações sobre livros e uma interface gráfica com Tkinter para exibição dos dados.

🚀 Funcionalidades
Conexão com banco de dados PostgreSQL

Criação automática da tabela livros

Geração e inserção de dados fictícios com a biblioteca Faker

Exibição dos livros cadastrados em uma interface gráfica com tkinter e ttk.Treeview

🛠️ Tecnologias Utilizadas
Python

PostgreSQL

psycopg2 (conector com o banco)

Faker (geração de dados fictícios)

Tkinter (interface gráfica)

📌 Observações
Toda vez que o programa for executado, 100 livros fictícios serão inseridos no banco. Para evitar duplicações, você pode ajustar o código para verificar se a tabela já contém dados antes de inserir.
